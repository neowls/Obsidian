Non-Goals

저장/로드 완성

Week 7 전까지는 full save가 아니라 debug checkpoint 또는 smoke recovery 기준으로 제한한다.

307호 내부

P0에서는 307호 문 앞 기억만 만든다. 내부 구현은 본편 후반 범위다.

새 Global Manager

기존 subsystem과 component 계약으로 먼저 해결한다.

UI Mock 선완성

Board/Report/Notebook은 runtime state 없이 완성하지 않는다.
