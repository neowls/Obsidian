Developer Flow

GameOnly Runtime HUD, Interaction Prompt, Toast

UNCUISubsystem이 HUD state를 캐시하고 WBP_NCPlayerHUD에 적용한다.

GameAndUI Complaint Board, Report Form, Notebook, Document Viewer

이동 입력은 막고 Back/Close는 즉시 처리한다. 데이터 변경은 runtime owner 요청으로만 수행한다.

UIOnly Pause Menu, Settings Menu

게임 입력을 정지하고 메뉴 focus를 유지한다. CommonUI는 향후 이 범위에서만 후보로 검토한다.

읽기

위젯은 complaint/evidence/document snapshot을 읽는다.

쓰기 요청

수락, 단서 등록, 보고 제출은 controller wrapper 또는 runtime subsystem API로 전달한다.

금지

GameState 배열 직접 수정, Level Actor hard reference, 진행 버튼 숨김형 오염 연출.

UML Notes

다이어그램 문서

개발자용 classDiagram, flowchart, sequenceDiagram, stateDiagram-v2는 NightCaretaker_UIUX_Diagrams.md에서 관리한다.

이 HTML은 브라우저에서 바로 열어 화면 톤과 구현 계약을 빠르게 확인하는 용도다.

P0 / P1

P0는 HUD, prompt, board, report, notebook, pause/settings다. Document viewer와 toast는 P0 연결 대상이지만 고급 오염 연출은 P1로 둔다.

CommonUI는 현재 런타임 기반이 아니므로 메뉴/설정 확장 후보로만 기록한다.
