State Matrix

상태축 낮은 단계 중간 단계 높은 단계 오디오 규칙
PowerState Normal: 안정적 hum PartialOutage, FloorOutage: 끊김/정적 EmergencyOnly, BasementIndependent: 좁은 대역 압박 조명 상태와 분리된 값을 오디오에 따로 저장하지 않는다.
TensionStage Stage0_Normal: 원인 추적 가능 Stage1_Discomfort, Stage2_RecordConflict: 위치/기록 timing drift Stage3_SpaceBreak, Stage4_Room307Focus: 거리/잔향 오염 전체 볼륨보다 방향감과 침묵 길이를 바꾼다.
Room307Stage Absent, NumberTrace: 전용 소리 없음 RecordIntrusion, ThirdFloorUnstable: 기록/3층 소리 DoorStay, Threshold, Interior: 문 앞/문턱 노출 문보다 건물 전체가 먼저 이상하게 들려야 한다.

Complaint Domain Matrix

도메인 대표 소리 단서 사용 주의
Complaint.Domain.Lighting 형광등 buzz, 안정기, 스위치 접점 Evidence.Audio로 고장음 확인 점멸음만 반복하지 않는다.
Complaint.Domain.Water 물방울, 배관 압력, 욕실 배수 누수 경로를 청각 단서로 제공 물의 경로를 전부 보여주지 않는다.
Complaint.Domain.Intercom 호출음, 통화 전 정적, 끊긴 발화 통신인지 생활 소음인지 의심하게 함 명확한 대사로 정체를 설명하지 않는다.
Complaint.Domain.LifeNoise TV 저음, 가구 끌림, 발소리, 낮은 말소리 누가 있는지 없는지 판단하는 단서 괴물음처럼 들리면 안 된다.
Complaint.Domain.Record 종이, 스탬프, 프린터, 보드 갱신음 기록 충돌을 청각적으로 확인 기록이 스스로 움직이는 직접 연출 과용 금지.
Complaint.Domain.Space 반사 지연, 거리감 불일치, 복도 끝 저역 실제 거리와 들리는 거리의 불일치 단서 공간 붕괴를 음악처럼 처리하지 않는다.
