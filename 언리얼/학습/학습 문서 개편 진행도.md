# 학습 문서 개편 진행도

> [!summary] 요약
> `언리얼/학습` Markdown 원본을 새 기술 문서 양식에 맞춰 정리하는 진행 기록이다.
> HTML 변환본, standalone HTML, 이미지, zip은 이번 1차 Markdown 개편 범위에서 제외한다.
> 문서 성숙도는 각 파일의 `status`, 개편 진행 상태는 `migration_status`로 분리해 추적한다.

## 핵심 결론

- 1차 목표는 Markdown 원본의 제목 구조, 요약, 핵심 결론, 관련 문서, 디버깅 체크리스트를 표준화하는 것이다.
- `status`는 `draft`, `review`, `stable`처럼 문서 성숙도를 나타내고, `migration_status`는 `done`, `needs-content`, `merge-candidate`처럼 개편 진행 상태를 나타낸다.
- 삭제나 병합은 하지 않고, 병합이 좋아 보이는 문서는 `merge-candidate`로 표시한다.

## 상태 값

| 속성 | 값 | 의미 |
| --- | --- | --- |
| `status` | `draft` | 내용 보강이 필요하거나 임시 문서인 상태 |
| `status` | `review` | 구조는 정리됐지만 추가 검토 가능성이 있는 상태 |
| `status` | `stable` | 운영 기준 문서처럼 현재 기준점으로 사용할 수 있는 상태 |
| `migration_status` | `done` | 구조 정리와 기본 검증 완료 |
| `migration_status` | `needs-content` | 구조는 있으나 내용 보강이 필요함 |
| `migration_status` | `merge-candidate` | 관련 문서에 병합 검토가 필요함 |
| `migration_status` | `skipped` | 이번 범위에서 제외 |
