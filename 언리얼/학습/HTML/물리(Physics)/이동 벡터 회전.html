이동 벡터 회전

입력으로 받은 2D 이동 벡터를 월드 X/Y축 그대로 쓰지 않고, 원하는 각도만큼 회전시켜 캐릭터 이동 방향으로 사용하는 방법입니다. AddMovementInput, FRotator::RotateVector, 2D 회전 행렬의 관계를 함께 정리합니다.

원본: 물리(Physics)/이동 벡터 회전.md 난이도: 이동 입력 수학 핵심: AddMovementInput, FRotator, RotateVector, 2D Rotation 검수 기준: Unreal Engine 5.7.4

한 줄 정의

이동 벡터 회전은 입력 벡터를 원하는 기준 좌표계로 돌린 뒤 AddMovementInput의 World Direction으로 넘기는 과정입니다. 예를 들어 입력이 (1, 0)이고 기준을 Yaw 45도로 틀면 이동 방향은 대략 (0.707, 0.707, 0)이 됩니다.

AddMovementInput이 기대하는 값

공식 5.7 문서 기준으로 AddMovementInput은 월드 공간 방향 벡터를 받고, Scale Value로 입력 세기를 곱합니다. 방향 벡터는 보통 정규화되어 있어야 하며, Character와 DefaultPawn은 누적된 이동 입력을 자동 처리합니다.

언리얼 코드 흐름

Enhanced Input에서 받은 FInputActionValue는 보통 2D 축 값입니다. 아날로그 스틱처럼 길이가 1을 넘을 수 있는 입력은 방향을 정규화하고, 실제 입력 세기는 별도 Scale로 넘기면 대각선 이동이 빨라지는 문제를 줄일 수 있습니다. 

void AMyCharacter::Move(const FInputActionValue& Value)
{
    FVector2D Input = Value.Get<FVector2D>();

    float Scale = 1.0f;
    const float SizeSquared = Input.SizeSquared();

    if (SizeSquared > 1.0f)
    {
        Input.Normalize();
    }
    else
    {
        Scale = FMath::Sqrt(SizeSquared);
    }

    FVector MoveDirection(Input.X, Input.Y, 0.0f);

    // 월드 기준 입력 방향을 Yaw 45도만큼 돌린다.
    const FRotator RotationOffset(0.0f, 45.0f, 0.0f);
    MoveDirection = RotationOffset.RotateVector(MoveDirection);

    AddMovementInput(MoveDirection, Scale);
}

원본 내용의 교정

FRotator는 각도를 도(degrees) 단위로 저장합니다. FMath::Sin, FMath::Cos 같은 삼각함수는 라디안 값을 받으므로 직접 공식을 구현할 때만 DegreesToRadians 변환이 필요합니다. 또한 TRotator::RotateVector는 공식 API와 공개 소스 흐름상 회전 행렬로 벡터를 변환한다고 이해하는 것이 맞고, FQuat::RotateVector와는 같은 결과를 낼 수 있는 별도 표현 방식입니다.

2D 회전 공식

Z축을 기준으로 2D 입력 벡터 (x, y)를 각도 theta만큼 회전하면 아래 공식을 사용합니다. Unreal 좌표계의 실제 진행 방향은 카메라 기준, 캐릭터 기준, 월드 기준 중 무엇을 선택하느냐에 따라 달라질 수 있지만, 평면 회전 자체는 동일합니다.

공식 의미
x' = x * cos(theta) - y * sin(theta) 회전 후 X 성분
y' = x * sin(theta) + y * cos(theta) 회전 후 Y 성분
z' = z Yaw 회전만 할 때 Z 성분은 그대로 둡니다. 
FVector2D RotateVector2D(const FVector2D& Vec, float AngleDegrees)
{
    const float AngleRadians = FMath::DegreesToRadians(AngleDegrees);
    const float CosTheta = FMath::Cos(AngleRadians);
    const float SinTheta = FMath::Sin(AngleRadians);

    return FVector2D(
        Vec.X * CosTheta - Vec.Y * SinTheta,
        Vec.X * SinTheta + Vec.Y * CosTheta
    );
}

45도 예시

(1, 0)을 45도 회전하면 cos(45)와 sin(45)가 모두 약 0.707이므로 결과는 (0.707, 0.707)입니다.

카메라 기준 이동과 구분

단순히 45도 틀어진 월드 기준 이동이면 RotationOffset.RotateVector가 충분합니다. 카메라가 바라보는 방향 기준 이동이라면 Controller Rotation에서 Yaw만 뽑아 Forward/Right 벡터를 만드는 구조가 더 일반적입니다.

언제 어떤 방식을 쓸까?

상황 추천 방식 이유
월드 기준을 일정 각도 회전 FRotator(0, Angle, 0).RotateVector 가장 읽기 쉽고 Unreal 좌표계와 잘 맞습니다.
2D 수식 검증 또는 UI 좌표 직접 cos/sin 공식 사용 평면 좌표 계산을 명확히 보여 주기 좋습니다.
많은 회전을 반복 계산 회전 객체나 sin/cos 값을 미리 계산 매 프레임 같은 각도의 삼각함수를 반복 계산하지 않아도 됩니다.
3D 임의 축 회전 FQuat 또는 Transform 사용 Yaw만이 아니라 임의 축과 보간이 중요할 때 안정적입니다.
