AI 지각(AI Perception)

AI Perception은 즉시 액션을 실행하는 노드가 아니라, Sense가 만든 자극을 Listener의 기억에 저장하고 gameplay 코드가 그 결과를 소비하도록 만드는 런타임 입력 계층입니다.

원본: AI 지각(AI Perception).md 핵심: System, Sense, Stimulus, Listener Memory 연결: Blackboard, Behavior Tree, EQS

Perception 입력 파이프라인

중심 틱은 UAIPerceptionComponent가 아니라 UAIPerceptionSystem입니다. 시스템이 Sense를 틱하고, Sense가 만든 FAIStimulus를 Listener가 기억합니다.

Source 등록Pawn 자동 등록 또는 StimuliSourceComponent 명시 등록
Sense TickSight, Hearing, Custom Sense가 업데이트 필요 여부를 판단
Stimulus 생성위치, 강도, 성공 여부, 만료 시간을 담은 자극 생성
ProcessStimuli타깃별 FActorPerceptionInfo에 sense별 자극 저장
Gameplay 소비Delegate, 조회 API, AIController callback으로 블랙보드 갱신

런타임 처리 흐름

시스템이 한 틱에서 하는 일

SourcesToRegister다음 틱에 등록할 자극 source를 처리합니다.
AgeStimuli활성 자극의 나이를 올리고 stale 여부를 판단합니다.
UAISense::Tick업데이트가 필요한 sense만 실제 감지 규칙을 수행합니다.
DeliverDelayedStimuli지연된 청각 이벤트 같은 자극을 listener에게 전달합니다.
ProcessStimuliListener memory 갱신 후 delegate를 브로드캐스트합니다.

Sense마다 비용이 다르게 흐릅니다

ProgressTime()과 Update()가 sense별 업데이트 타이밍을 나누므로, 모든 감각이 매 프레임 같은 비용으로 도는 모델로 보면 안 됩니다.

Stimulus와 타깃 기억

UnitFAIStimulusAge, ExpirationAge, Strength, Location, Type, bSuccessfullySensed를 가진 한 번의 감지 결과
TargetFActorPerceptionInfoTarget actor에 대해 sense ID별 마지막 stimulus 배열을 보관
LocationDominantSense여러 sense가 있을 때 마지막 위치 해석 우선순위를 결정
현재 감지HasAnyCurrentStimulus()는 아직 active한 자극을 봅니다.
알고 있는 대상HasAnyKnownStimulus()는 현재 놓쳤어도 기억이 남은 대상을 포함합니다.
완전 망각bForgetStaleActors가 꺼져 있으면 stale actor가 자동으로 완전히 지워지지 않을 수 있습니다.

Blackboard / Behavior Tree 연결

Perception은 블랙보드를 직접 바꾸지 않습니다. 보통 delegate를 받은 gameplay 코드가 감지 결과를 의사결정용 키로 옮깁니다.

Perception자극 수신Sight 성공, Hearing 이벤트, 감지 실패/만료
Code결과 해석GetActorsPerception() 또는 stimulus 상태 확인
Blackboard키 갱신TargetActor, LastKnownLocation, InvestigateLocation
Behavior Tree재평가Decorator observer abort나 Service 갱신으로 분기 변경
Delegate사용 감각
OnPerceptionUpdated여러 액터를 한 번에 받은 배치 이벤트가 필요할 때
OnTargetPerceptionUpdated액터와 stimulus 단위로 즉시 반응할 때
OnTargetPerceptionInfoUpdatedsource actor가 무효화될 수 있어 TargetId 기반 bookkeeping이 필요할 때
OnTargetPerceptionForgotten완전히 잊은 대상에 대한 정리가 필요할 때

복습 질문

Q1. Perception의 중심 틱은 어느 객체가 담당하는가?

UAIPerceptionSystem이 listener, source, sense를 관리하고 업데이트가 필요한 sense를 틱합니다.

Q2. DominantSense는 무엇을 바꾸는가?

감지 가능 여부가 아니라 여러 sense 자극 중 마지막 위치를 해석할 때의 우선순위를 바꿉니다.
