AI Controller / Brain

AI 컨트롤러와 BrainComponent

AIController는 Pawn, Blackboard, Brain, PathFollowing을 묶는 소유자이고, BrainComponent는 BehaviorTreeComponent 같은 실제 AI 논리 구현체로 연결되는 공통 인터페이스입니다.

원본: AI 컨트롤러(AIController)와 BrainComponent.md 핵심: UseBlackboard, RunBehaviorTree, AI Message

AI 실행 계층 지도

AAIControllerPawn을 Possess하고 Brain, Blackboard, PathFollowing을 조정합니다.
UBrainComponentAI 로직의 start/stop/message/resource lock 공통 인터페이스입니다.
UBehaviorTreeComponentBrainComponent의 Behavior Tree 구현체입니다.
UBlackboardComponentTree와 Task가 읽고 쓰는 상태 저장소입니다.
UPathFollowingComponentMoveTo 요청을 실제 경로 추종으로 실행합니다.

BrainComponent 자체는 실행 로직이 거의 없습니다

Base class의 StartLogic(), StopLogic()는 비어 있고, 실제 동작은 UBehaviorTreeComponent 같은 하위 클래스가 구현합니다.

RunBehaviorTree의 실제 의미

BTAsset 검사실행할 Behavior Tree asset이 유효한지 확인
UseBlackboard트리에 Blackboard가 필요하면 component 생성/초기화 보장
Brain 확인현재 Brain이 UBehaviorTreeComponent인지 확인
BT Component 보장아니면 새 component를 만들고 Brain으로 교체
StartTreeStartTree(*BTAsset, Looped)로 실행 시작
UseBlackboard자산을 Controller의 런타임 BlackboardComponent에 연결합니다.
OnPossessPawn 준비, Blackboard 재초기화, 조건부 StartLogic 진입점입니다.
Self KeySetPawn() 경로에서 현재 Pawn 참조로 갱신됩니다.

Brain 메시지 시스템

BT Task의 비동기 완료는 WaitForMessage()와 BrainComponent의 message queue를 통해 이어집니다.

TaskWaitForMessageMoveFinished, QueryFinished 같은 메시지를 기다림
BrainMessagesToProcess즉시 처리하지 않고 큐에 쌓음
TickHandleMessageobserver에게 메시지 전달
BTFinishLatentTask비동기 task가 성공/실패로 종료

리소스 락과 Pause/Resume

GameplayTask가 Logic 리소스를 점유할 때

LockResource처음 잠기면 AI logic을 pause합니다.
PauseLogicBrain이 현재 로직을 일시 중단합니다.
ClearResourceLock락이 모두 풀리면 resume 후보가 됩니다.
ResumeLogic필요하면 예약된 restart도 처리합니다.

복습 질문

Q1. BrainComponent와 BehaviorTreeComponent는 같은가?

아닙니다. BehaviorTreeComponent는 BrainComponent의 한 구현체입니다.

Q2. RunBehaviorTree가 보장하는 세 가지는?

Blackboard 보장, BT용 Brain 구현체 보장, Tree 실행 시작입니다.
