Behavior Tree Memory

블랙보드(Blackboard)

Blackboard는 키 이름을 값으로 매핑하는 단순 맵이 아니라, 키 타입이 정의한 크기와 규칙으로 packed memory를 만들고 값 변화 observer를 통해 Behavior Tree 재평가를 유도하는 typed memory system입니다.

원본: 행동 트리/블랙보드(Blackboard).md 핵심: UBlackboardData, UBlackboardComponent, UBlackboardKeyType

에셋 정의와 런타임 메모리

UBlackboardKeyType값 크기, 비교, 설명, 위치 추출 같은 타입별 동작 정의

InitializeBlackboard가 하는 일

자산 확인동일 에셋이면 불필요한 재초기화를 피합니다.
부모 체인상위 Blackboard를 포함해 key id를 갱신합니다.
메모리 계산키 타입의 ValueSize와 instance 필요 여부를 수집합니다.
PackingValueMemory와 ValueOffsets를 계산합니다.
초기화각 key type의 InitializeKey()를 호출합니다.

슬롯 기반 시스템으로 읽습니다

Blackboard는 키 이름 해시를 매번 찾는 컨테이너라기보다, 미리 정의된 key id와 offset으로 접근하는 런타임 메모리 구조에 가깝습니다.

Observer 모델

Blackboard의 중요한 축은 값 저장보다 값 변화 알림입니다. 이 알림이 Decorator abort와 Behavior Tree 재평가의 기반이 됩니다.

Service/TaskSetValueAI 지식 또는 행동 결과를 키에 기록
BlackboardNotifyObservers등록된 observer에게 변경 통지
DecoratorAbort 판단조건 변화에 따라 현재 브랜치 중단 또는 재탐색
TreeFlow 변경추격, 공격, 순찰 브랜치가 바뀜

Instance Synced는 네트워크 복제가 아닙니다

bInstanceSynced는 로컬 AI 시스템 내부에서 관련 Blackboard instance를 맞추는 기능이지, 멀티플레이 replication 기능이 아닙니다.

복습 질문

Q1. Blackboard 값의 실제 저장소는?

UBlackboardComponent의 ValueMemory와 ValueOffsets입니다.

Q2. 이벤트 주도형 BT와 Blackboard의 연결점은?

키 변경 시 NotifyObservers()가 Decorator observer abort와 재평가를 유도합니다.
