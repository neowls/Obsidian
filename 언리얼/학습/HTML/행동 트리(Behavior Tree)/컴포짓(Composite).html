Behavior Tree

컴포짓(Composite)

Composite는 Behavior Tree 브랜치의 루트 역할을 하며, 자식 노드를 어떤 순서와 규칙으로 실행할지 결정합니다. Selector, Sequence, Simple Parallel의 차이를 이해하면 BT 구조가 훨씬 읽기 쉬워집니다.

원본: 행동 트리(Behavior Tree)/컴포짓(Composite).md 난이도: BT 흐름 제어 핵심: Selector, Sequence, Simple Parallel 검수 기준: Unreal Engine 5.7.4

한 줄 정의

Composite는 자식 브랜치 실행 규칙을 정하는 Behavior Tree의 흐름 제어 노드입니다. 공식 5.7 노드 레퍼런스에서도 Composite는 브랜치의 루트와 실행 규칙을 정의하며, Decorator와 Service를 붙일 수 있는 노드로 설명됩니다.

Root에는 Composite만 연결합니다

Behavior Tree의 Root 바로 아래에는 Composite가 연결됩니다. Root는 Blackboard와 트리 설정을 잡는 시작점이고, 실제 의사결정 흐름은 첫 Composite부터 시작한다고 보면 됩니다.

Composite 종류

노드 실행 규칙 성공/실패 조건 대표 사용
Selector 왼쪽에서 오른쪽으로 자식을 실행합니다. 자식 하나가 성공하면 Selector도 성공합니다. 모두 실패하면 실패합니다. 공격 가능하면 공격, 아니면 추격, 아니면 순찰처럼 후보 중 하나 선택
Sequence 왼쪽에서 오른쪽으로 자식을 순서대로 실행합니다. 자식 하나가 실패하면 Sequence도 실패합니다. 모두 성공해야 성공합니다. 타겟 바라보기, 사거리 확인, 공격처럼 절차를 차례대로 수행
Simple Parallel 메인 Task 하나와 백그라운드 브랜치를 함께 실행합니다. 메인 Task 완료 후 Finish Mode에 따라 즉시 끝내거나 백그라운드를 기다립니다. 이동하는 동안 주변 감시, 공격 중 보조 상태 관찰

선택 기준

Selector 대안 선택 여러 행동 후보 중 먼저 성공하는 하나를 고릅니다.
Sequence 절차 실행 모든 단계가 성공해야 전체 행동이 성공합니다.
Simple Parallel 주 작업 + 보조 관찰 메인 Task를 수행하는 동안 보조 브랜치를 함께 돌립니다.

Simple Parallel을 과용하지 않습니다

언리얼 Behavior Tree는 Simple Parallel, Service, Decorator의 Observer Aborts로 동시성에 가까운 행동을 구성합니다. 복잡한 병렬 구조를 먼저 만들기보다, Service로 Blackboard를 갱신하고 Decorator Abort로 더 높은 우선순위 브랜치가 개입하게 만드는 편이 관리하기 쉽습니다.

복습 질문

1. 후보 행동 중 하나를 고를 때 적합한 Composite는?

정답: Selector입니다.

2. 모든 자식이 성공해야 성공하는 Composite는?

정답: Sequence입니다.

3. Simple Parallel의 두 연결은 무엇인가?

정답: 메인 Task와 백그라운드 브랜치입니다.

4. Composite에 붙을 수 있는 보조 노드는?

정답: Decorator와 Service입니다.

관련 노트

  • 비헤이비어 트리(Behavior Tree): 전체 구조와 실행 흐름
  • 데코레이터(Decorator): 브랜치 진입 조건과 중단 조건
  • 서비스(Service): 활성 브랜치의 주기적 정보 갱신
  • 태스크(Task): Composite가 실행하는 실제 작업
