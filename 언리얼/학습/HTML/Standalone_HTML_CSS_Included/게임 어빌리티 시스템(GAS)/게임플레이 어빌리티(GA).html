Gameplay Ability System

게임플레이 어빌리티(GA)

Gameplay Ability는 공격, 회피, 마법, 패시브 같은 게임 액션의 실행 흐름입니다. ASC에 Spec으로 등록된 뒤 조건 검사를 통과하면 활성화되고, 비용과 쿨다운을 확정한 뒤 반드시 종료되어야 합니다.

원본: 게임 어빌리티 시스템(GAS)/게임플레이 어빌리티(GA).md 난이도: 실행 흐름 기초 핵심: GiveAbility, TryActivateAbility, ActivateAbility, EndAbility 검수 기준: Unreal Engine 5.7.4

GA 발동 흐름 실험판

Gameplay Ability는 입력이 들어오자마자 무조건 실행되는 것이 아니라, ASC가 Spec을 찾고 조건을 검사한 뒤 비용과 쿨다운을 확정하고 종료까지 관리합니다.

실행 시나리오
1Grant SpecGiveAbility
2RequestTryActivateAbility
3CheckCanActivateAbility
4CommitCost/Cooldown
5TaskMontage/TargetData
6EndEndAbility

Run을 누르면 활성화 성공, 조건 차단, 취소 종료 경로가 단계별로 표시됩니다.

한 줄 정의

Gameplay Ability는 액터가 수행할 수 있는 액션 명령입니다. 단순한 공격뿐 아니라 타겟 선택, 애니메이션 대기, 비용 지불, 쿨다운 적용, 이펙트 적용까지 하나의 실행 흐름으로 묶을 수 있습니다.

Spec과의 관계

ASC는 어빌리티 클래스를 직접 막연히 실행하지 않습니다. 먼저 FGameplayAbilitySpec으로 어빌리티를 등록하고, 활성화 시에는 그 Spec과 연결된 어빌리티 인스턴스 또는 CDO가 실행됩니다.

Ability Class

UGameplayAbility를 상속한 C++ 또는 Blueprint 클래스입니다. 능력의 기본 로직과 설정을 담습니다.

Ability Spec

ASC에 등록된 어빌리티 항목입니다. 레벨, 입력, SourceObject, Handle 같은 실행 정보를 연결합니다.

ActorInfo

어빌리티를 소유한 Actor, Avatar Actor, ASC, Controller 같은 실행 문맥을 제공합니다.

ActivationInfo

예측 키와 발동 방식 등 활성화 상태를 담습니다. 네트워크 예측을 볼 때 중요합니다.

GA 발동 과정

전체 흐름은 “등록된 어빌리티만 활성화할 수 있다”는 규칙에서 시작합니다. 서버가 부여하고, ASC가 조건을 검사하며, 활성화된 GA는 스스로 끝나야 합니다.

1. Grant ASC에 등록 GiveAbility로 GA를 Spec 형태로 부여합니다.
2. Request 활성화 요청 입력, 태그, 클래스, Spec Handle 등을 통해 ASC에 실행을 요청합니다.
3. Check 조건 검사 CanActivateAbility가 태그, 비용, 쿨다운, 권한 상태를 확인합니다.
4. Activate 실행 시작 ActivateAbility에서 Task, 몽타주, 이펙트 적용 같은 로직을 시작합니다.
5. End 종료 완료 또는 취소 시 EndAbility로 실행 상태를 정리합니다.

등록과 활성화 코드 감각

프로젝트마다 입력 바인딩 구조는 다르지만, 기본 감각은 Spec을 부여하고 그 Handle 또는 조건을 통해 ASC에 활성화를 요청하는 것입니다. 

// 서버 권한에서 어빌리티 부여
FGameplayAbilitySpecHandle AbilityHandle = AbilitySystemComponent->GiveAbility(
    FGameplayAbilitySpec(AbilityClass, AbilityLevel, InputID, SourceObject)
);

// 이후 입력 또는 게임 로직에서 활성화 요청
AbilitySystemComponent->TryActivateAbility(AbilityHandle);

중요한 종료 규칙

GA가 정상 완료되었는데 EndAbility를 호출하지 않으면 GAS는 그 어빌리티가 아직 실행 중이라고 판단할 수 있습니다. 그 결과 같은 어빌리티 재사용이나 태그 기반 차단 로직이 계속 막힐 수 있습니다.

활성화 호출 순서

학습할 때는 TryActivateAbility가 먼저 활성화 요청을 받고, 내부에서 CanActivateAbility로 조건을 확인한 뒤 CallActivateAbility를 거쳐 사용자가 구현한 ActivateAbility로 들어간다고 보면 됩니다. 따라서 조건 검사는 ActivateAbility 시작 후에 처음 하는 것이 아니라, 발동 요청 단계에서 이미 한 번 걸러지는 구조입니다.

GA의 주요 함수

함수 역할 실무에서 보는 기준
CanActivateAbility 어빌리티가 지금 실행 가능한지 확인합니다. 태그 차단, 쿨다운, 비용, 타겟 조건을 여기에서 판단해야 하는가?
ActivateAbility 어빌리티가 실제로 시작될 때 호출됩니다. 비용 확정, Task 시작, 몽타주 재생, TargetData 대기를 어디서 시작할 것인가?
CommitAbility 비용 지불과 쿨다운 적용을 확정합니다. 이 액션은 어느 시점에 되돌릴 수 없는 실행으로 간주되는가?
CancelAbility 외부 요청이나 조건 변화로 어빌리티를 취소합니다. 취소 시 몽타주, Task, 태그, 이펙트 정리가 필요한가?
EndAbility 정상 종료 또는 취소 종료 시 실행 상태를 마무리합니다. 모든 성공/실패/취소 경로가 반드시 종료로 이어지는가?

5.7 기준으로 함께 봐야 할 설정

항목 의미 학습 포인트
Net Execution Policy 어빌리티 실행 요청과 예측을 어느 쪽에서 처리할지 정합니다. 클라이언트 예측 스킬인지, 서버 전용 판정인지 먼저 결정합니다.
Replication Policy 어빌리티의 상태와 이벤트 복제 방식을 다룹니다. Net Execution Policy와 같은 말이 아니므로 따로 확인합니다.
CommitAbilityCost / CommitAbilityCooldown 비용과 쿨다운을 각각 확정할 수 있습니다. 차징, 선딜, 명중 후 비용 같은 설계에서는 Commit 시점을 분리해 봅니다.
Ability Task 몽타주, 타겟 데이터, 입력, 대기 이벤트를 비동기로 이어 줍니다. Task는 대개 인스턴스 상태와 Delegate 정리가 필요하므로 인스턴싱 정책과 같이 봅니다.

어빌리티 안에 남는 실행 정보

Gameplay Ability Runtime Context

활성화된 GA는 자신이 어떤 Spec에서 실행되었고, 어떤 액터 문맥에서 실행 중이며, 어떤 예측/권한 상태에 있는지를 함께 받습니다.

SpecHandle

ASC 내부에서 이 어빌리티 등록 정보를 식별하는 Handle입니다.

ActorInfo

OwnerActor, AvatarActor, ASC, Controller 같은 실행 주체 정보를 담습니다.

ActivationInfo

발동 방식과 예측 키를 포함한 활성화 상태 정보입니다.

GA로 만들기 좋은 것과 애매한 것

잘 맞는 예

  • 공격, 사격, 회피, 질주, 마법, 패시브 효과
  • 비용, 쿨다운, 태그 차단이 필요한 액션
  • 타겟팅과 애니메이션 대기가 포함된 복합 액션
  • 네트워크 예측이나 서버 권한 처리가 필요한 플레이어 능력

다시 판단할 예

  • 순수 UI 조작이나 메뉴 상호작용
  • GAS 상태와 관계없는 단순 로컬 연출
  • 비용, 쿨다운, 태그, 복제가 전혀 필요 없는 작은 기능
  • 매 프레임 상태를 계속 갱신해야 하는 일반 컴포넌트성 로직

복습 질문

1. GA를 실행하기 전에 ASC에는 무엇이 등록되어 있어야 하는가?

정답: 해당 어빌리티의 FGameplayAbilitySpec이 등록되어 있어야 합니다.

2. ActivateAbility에서 CommitAbility를 호출하는 의미는?

정답: 비용 지불과 쿨다운 적용처럼 실행을 확정하는 단계입니다.

3. EndAbility를 빼먹으면 어떤 문제가 생길 수 있는가?

정답: GAS가 어빌리티를 계속 실행 중으로 보고 재사용이나 다른 어빌리티 활성화를 막을 수 있습니다.

4. ActorInfo에는 어떤 정보가 들어가는가?

정답: OwnerActor, AvatarActor, ASC, Controller 등 어빌리티 실행 주체와 관련된 정보가 들어갑니다.
