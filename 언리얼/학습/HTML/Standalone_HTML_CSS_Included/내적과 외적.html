Math / FVector

내적과 외적

내적은 두 벡터가 얼마나 같은 방향을 보는지 스칼라로 알려주고, 외적은 두 벡터가 만드는 평면의 수직 방향과 면적을 벡터로 알려줍니다. 언리얼에서는 FVector::DotProduct와 FVector::CrossProduct를 사용합니다.

원본: 내적과 외적.md 난이도: 기초 수학 핵심: DotProduct, CrossProduct, Normalize, Degrees 검수 기준: Unreal Engine 5.7.4

벡터 관계 시각화

아래 실험판은 정규화된 Forward 벡터와 Target 방향 벡터를 기준으로 내적과 외적을 동시에 보여줍니다. 슬라이더를 움직이면 각도, 내적 값, 외적 Z 부호, 투영 길이, 평행사변형 넓이가 함께 바뀝니다.

각도 theta 45도 두 방향이 벌어진 정도
Dot(A, B) 0.707 앞쪽 원뿔 안
Cross(A, B).Z 0.707 UE 기준 오른쪽
외적 크기 0.707 두 단위 벡터가 만드는 넓이

내적(Dot Product)

내적은 두 벡터의 크기와 두 벡터 사이 각도의 코사인 값을 곱한 값입니다. 결과는 방향이 없는 스칼라이며, 방향 판정과 시야각 계산에 자주 사용됩니다. 

a · b = |a| |b| cos(theta)
상황 정규화된 벡터의 내적 의미
같은 방향 1 각도 0도, 완전히 앞쪽
수직 0 각도 90도, 옆쪽
반대 방향 -1 각도 180도, 뒤쪽

원본 예제의 보정

FMath::Acos에 넣는 값은 -1부터 1 범위여야 합니다. 적 위치까지의 방향 벡터를 정규화하지 않고 내적하면 거리까지 곱해져 범위를 벗어날 수 있으므로, 각도를 구할 때는 두 벡터를 정규화해야 합니다.

외적(Cross Product)

외적은 두 벡터에 모두 수직인 벡터를 반환합니다. 외적의 길이는 두 벡터가 만드는 평행사변형의 넓이이고, 연산 순서를 바꾸면 방향이 반대로 바뀝니다. 

a x b = |a| |b| sin(theta) n
a x b = -(b x a)

법선 계산

삼각형의 두 변을 외적하면 면의 법선 방향을 얻을 수 있습니다.

좌우 판정

Forward와 TargetDirection의 외적 Z 부호로 대상이 왼쪽인지 오른쪽인지 판단할 수 있습니다.

평행 판정

두 벡터가 평행하면 외적 길이는 0에 가까워집니다.

토크 계산

힘이 작용하는 위치 벡터와 힘 벡터의 외적으로 회전력을 표현할 수 있습니다.

언리얼 예제

정면/후면처럼 단순 방향 판정만 필요하면 각도를 구하지 않고 내적 임계값을 바로 비교하는 편이 빠르고 안정적입니다. 각도가 꼭 필요할 때만 Acos와 라디안-도 변환을 사용합니다. 

const FVector ToEnemy = (EnemyActorLocation - GetActorLocation()).GetSafeNormal();
const FVector Forward = GetActorForwardVector().GetSafeNormal();

const float Dot = FVector::DotProduct(Forward, ToEnemy);

// cos(45deg) ~= 0.707, cos(135deg) ~= -0.707
const bool bInFrontCone = Dot >= FMath::Cos(FMath::DegreesToRadians(45.0f));
const bool bBehindCone = Dot <= FMath::Cos(FMath::DegreesToRadians(135.0f));

// 좌우 판정: Unreal의 일반 캐릭터 축 기준으로 Z 부호를 많이 사용한다.
const FVector Cross = FVector::CrossProduct(Forward, ToEnemy);
const bool bEnemyOnRight = Cross.Z > 0.0f;

각도 계산이 필요할 때

FMath::Acos(Dot)는 라디안을 반환합니다. 사람이 읽는 각도로 표시하려면 FMath::RadiansToDegrees로 변환합니다.

복습 질문

Q1. 정규화된 두 벡터의 내적이 0이면 어떤 관계인가?

두 벡터가 서로 수직입니다.

Q2. FMath::Acos에 넣기 전에 해야 할 일은?

두 벡터를 정규화하거나 내적 값을 -1..1로 클램프해 유효 범위를 보장해야 합니다.

Q3. 외적에서 연산 순서가 중요한 이유는?

A x B와 B x A는 방향이 반대인 벡터를 반환하기 때문입니다.
