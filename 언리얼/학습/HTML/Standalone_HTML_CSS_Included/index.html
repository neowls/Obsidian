  • 언리얼 포인터

  • 트레이스(Trace)

  • 에셋 매니저(Asset Manager)

  • 에셋 레지스트리(Asset Registry)

게임 어빌리티 시스템(GAS)

  • GAS Documentation 종합 정리
    원본 대형 GAS Documentation을 5.7.4 기준 학습 로드맵, 최신화 포인트, 프로젝트 적용 체크리스트로 재구성합니다.
  • 게임플레이 어빌리티 시스템(GAS)
    ASC를 중심으로 Gameplay Ability, Gameplay Effect, Attribute, Tag, Cue, Task의 역할을 정리합니다.
  • 어빌리티 시스템 컴포넌트(ASC)
    GAS의 중심 컴포넌트인 ASC의 보유 데이터, Owner/Avatar, 권한과 복제 기준을 정리합니다.
  • 어빌리티 시스템 컴포넌트의 입력 처리
    InputID, AbilitySpecInputPressed/Released, TryActivateAbility로 이어지는 입력 라우팅 흐름을 정리합니다.
  • 게임플레이 어빌리티 타겟 액터(TA)
    Target Actor, World Reticle, TargetDataHandle을 중심으로 GAS 타겟팅 흐름을 정리합니다.
  • 게임플레이 어빌리티(GA)
    ASC 등록부터 활성화, 비용 확정, 취소, 종료까지 Gameplay Ability의 실행 생명주기를 정리합니다.
  • 게임플레이 어빌리티(GA)의 인스턴싱 옵션
    NonInstanced, InstancedPerActor, InstancedPerExecution의 차이와 선택 기준을 정리합니다.
  • 어빌리티 태스크(AT)
    GA 안에서 몽타주, 입력, 타겟팅 같은 비동기 작업을 처리하는 Ability Task 흐름을 정리합니다.
  • 어빌리티 태스크(AT)의 제작 규칙
    커스텀 UAbilityTask의 생성 함수, 델리게이트, Activate, OnDestroy 구현 규칙을 정리합니다.
  • 게임플레이 이펙트(GE)
    Attribute와 Gameplay Tag를 바꾸는 GE의 지속 정책, Modifier, 계산 방식을 정리합니다.
  • 어트리뷰트 세트(Attribute Set)
    FGameplayAttributeData, BaseValue/CurrentValue, Attribute Set 콜백과 클램프 기준을 정리합니다.
  • 메타(Meta) 어트리뷰트
    Damage 같은 임시 Attribute를 후처리해 Health, Shield, 무적 규칙으로 분배하는 패턴을 정리합니다.
  • 기간형 게임플레이 이펙트
    Duration/Infinite GE의 Active 상태, CurrentValue 보정, 스택과 주기 실행 정책을 정리합니다.
  • 레벨과 커브 테이블
    GE Level, ScalableFloat, Curve Table을 이용한 레벨별 수치 설계를 정리합니다.
  • 게임플레이 이펙트의 생성 과정
    GameplayEffectContextHandle, GameplayEffectSpecHandle을 만들고 ASC에 적용하는 순서를 정리합니다.
  • 게임플레이 큐(GC)
    파티클, 사운드, 카메라 효과를 담당하는 GameplayCueNotify와 Cue 이벤트 흐름을 정리합니다.
  • 게임플레이 태그(Tag)
    FGameplayTag, GameplayTagContainer 검색, Ability 실행 조건 태그를 정리합니다.
  • 게임플레이 어빌리티 스펙(Spec)
    ASC가 어빌리티를 보유하고 제어하는 단위인 FGameplayAbilitySpec과 Spec Handle의 역할을 정리합니다.
