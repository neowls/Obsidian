Behavior Tree

데코레이터(Decorator)

Decorator는 Behavior Tree의 조건문입니다. Composite 또는 Task에 붙어서 해당 브랜치나 노드가 실행 가능한지 판단하고, 조건 변화에 따라 실행 중인 행동을 중단시킬 수도 있습니다.

원본: 행동 트리(Behavior Tree)/데코레이터(Decorator).md 난이도: BT 조건 분기 핵심: Condition, Blackboard, Observer Aborts 검수 기준: Unreal Engine 5.7.4

Observer Aborts 실험판

Decorator는 조건을 검사할 뿐 아니라, Observer Aborts 설정에 따라 실행 중인 낮은 우선순위 브랜치를 중단하거나 자기 브랜치를 멈출 수 있습니다.

Observer Aborts
SelectorChase 브랜치가 Patrol보다 높은 우선순위
DecoratorTargetActor Is Set
Task: Chase높은 우선순위
Fallback조건 없음
Task: Patrol현재 실행 중

초기 상태는 Patrol 실행 중입니다. TargetActor와 Abort 모드를 바꿔 전환 여부를 확인하세요.

한 줄 정의

Decorator는 브랜치 진입 가능 여부와 실행 중단 조건을 정의하는 Behavior Tree 보조 노드입니다. 조건을 Task 리프 노드로 만들지 않고 Decorator로 붙이면, 트리에서 실제 행동과 판단 조건을 분명히 구분할 수 있습니다.

가장 흔한 Decorator

Blackboard Decorator는 특정 Blackboard Key가 설정되어 있는지, 특정 값과 같은지, Object가 유효한지 등을 검사합니다. 예를 들어 TargetActor Is Set이면 추격 브랜치를 열고, 비어 있으면 순찰 브랜치로 내려가게 만들 수 있습니다.

Observer Aborts

Decorator가 단순히 진입 시점만 검사한다면 이벤트 주도형 Behavior Tree의 장점을 제대로 쓰기 어렵습니다. Observer Aborts는 조건이 바뀌었을 때 현재 실행 중인 브랜치를 중단하거나 낮은 우선순위 브랜치를 밀어낼 수 있게 합니다.

옵션 의미 사용 예
None 조건 변화가 실행 중인 트리를 중단하지 않습니다. 한 번 시작하면 끝까지 가도 되는 단순 행동
Self 자기 브랜치 조건이 깨지면 현재 브랜치를 중단합니다. 타겟을 잃으면 추격 Task 중단
Lower Priority 조건이 참이 되면 더 낮은 우선순위 브랜치를 중단하고 이 브랜치로 전환합니다. 순찰 중 플레이어를 발견하면 추격으로 즉시 전환
Both Self와 Lower Priority를 모두 적용합니다. 전투/추격처럼 조건 변화에 민감한 핵심 브랜치

설계 패턴

좋은 사용

  • Blackboard Key 기반 분기 조건
  • 쿨다운, 거리, 시야, 상태 태그 같은 실행 가능 조건
  • 조건 변화 시 브랜치 중단 또는 우선순위 전환

피해야 할 사용

  • 긴 시간 걸리는 작업을 Decorator 안에서 처리
  • Blackboard 값을 계속 갱신하는 로직을 Decorator에 넣기
  • 실제 이동/공격 같은 액션을 Decorator에서 수행

Blueprint Decorator 주의

5.7 API에서 Blueprint 기반 Decorator는 Task와 Service보다 수명주기와 latent action 정리가 까다롭다고 설명됩니다. 복잡한 대기나 비동기 처리는 Decorator보다 Service/Task 또는 C++ 구현을 검토하는 편이 안전합니다.

복습 질문

1. Decorator의 기본 역할은?

정답: 브랜치나 노드가 실행 가능한지 조건을 검사하는 것입니다.

2. 순찰 중 타겟 발견 시 추격으로 즉시 바꾸려면?

정답: 높은 우선순위 추격 브랜치의 Decorator에 Lower Priority Abort를 검토합니다.

3. 조건이 깨졌을 때 자기 브랜치를 중단하는 옵션은?

정답: Self Abort입니다.

4. 조건 값을 주기적으로 갱신하는 역할은 Decorator보다 무엇에 적합한가?

정답: Service입니다.

관련 노트

  • 비헤이비어 트리(Behavior Tree): BT 전체 구조
  • 컴포짓(Composite): Decorator가 붙는 브랜치 루트
  • 서비스(Service): 조건 판단에 필요한 Blackboard 값 갱신
  • 태스크(Task): 조건을 통과한 뒤 수행할 실제 작업
