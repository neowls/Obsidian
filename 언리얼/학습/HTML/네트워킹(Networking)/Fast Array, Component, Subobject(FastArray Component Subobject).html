Replication / Actor Channel

Fast Array, Component, Subobject

이 주제의 핵심은 Actor 하나만 복제하는 것이 아니라, Actor Channel이 동적 배열 원소, replicated component, registered subobject를 어떤 dirty 규칙과 생성 순서로 흘려보내는가입니다.

원본: FastArray Component Subobject.md 핵심: Fast Array delta, ReadyForReplication, Registered Subobject List

Actor Channel 위의 복제 단위

Actor ChannelActor, replicated component, subobject가 공유하는 전송 통로입니다.
Fast Array동적 배열 원소를 ID와 ReplicationKey 중심으로 delta 전송합니다.
Replicated Component독립 채널이 아니라 owner actor channel 위에서 함께 전송됩니다.
Registered Subobjectactor/component registry를 channel이 순회해 상태를 보냅니다.

Fast Array Dirty 계약

ReplicationID원소의 네트워크 식별자입니다. 게임플레이 의미로 쓰지 않습니다.
ReplicationKey원소가 dirty된 버전입니다.
ArrayReplicationKey배열 레벨 변경 버전입니다.
추가/수정MarkItemDirty()
삭제MarkArrayDirty()
Deltabase state와 current state 비교
CallbacksAdd, Change, Remove, PostReceive

삭제는 item dirty가 아닙니다

원소가 사라진 사실은 배열 레벨에서 다시 계산해야 하므로 삭제 후에는 MarkArrayDirty()가 핵심입니다.

Channel 전송 순서

Actor Subobjectsactor 소유 subobject content block 작성
Componentsreplicated component 순회
Component Subobjectscomponent가 가진 registered subobject 먼저 작성
Component Body마지막에 component 자체 전송

생성 순서가 중요합니다

수신 측에서 component가 참조할 subobject가 먼저 만들어져야 하므로 subobject가 component 본체보다 먼저 전송되는 순서가 있습니다.

복습 질문

Q1. Fast Array가 일반 배열 복제와 다른 점은?

원소 identity와 ReplicationKey를 직접 관리하는 custom delta serializer입니다.

Q2. Component는 독립 채널을 갖는가?

아닙니다. owner actor channel 위에서 subobject처럼 전송됩니다.
