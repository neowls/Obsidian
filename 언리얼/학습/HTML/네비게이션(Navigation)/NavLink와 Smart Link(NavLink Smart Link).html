NavLink와 Smart Link

NavLink는 끊어진 NavMesh 구간을 pathfinding에 연결하고, Smart Link는 그 구간을 런타임에서 enable/disable하거나 점프, 사다리, 문 통과 같은 custom movement로 전환합니다.

Simple Link정적 경로 연결 데이터입니다. 프록시 하나에 여러 개 둘 수 있습니다.
Smart Link동적 enable/disable, area 변경, custom move callback을 가진 런타임 링크입니다.

PathFollowing에서 NavLink 처리

SetMoveSegment현재 start/end path point를 잡습니다.
PathPt1 검사다음 point에 CustomNavLinkId가 있으면 link를 캐시합니다.
Reach Conditionlink 시작점 도달 판정을 일반 점과 다르게 적용할 수 있습니다.
PathPt0 검사현재 point가 custom link면 StartUsingCustomLink() 호출
FinishResumePathFollowing() 또는 FinishUsingCustomLink()로 복귀

Custom move 후 복귀를 빼먹으면 멈춥니다

Smart Link에서 직접 이동을 제어했다면 마지막에 path following의 custom-link 상태를 반드시 해제해야 다음 세그먼트로 넘어갑니다.

UNavLinkCustomComponent의 핵심

CustomLinkIdNavigationSystem에 등록되는 식별 가능한 링크 객체가 됩니다.
SetEnabledAreanavmesh rebuild 없이 enabled/disabled area를 런타임에서 갱신합니다.
OnLinkMoveStarteddelegate가 있으면 custom move로 진입하고 moving agent를 추적합니다.
HasMovingAgents링크 상태를 바꾸기 전 이미 사용 중인 agent가 있는지 확인합니다.

복습 질문

Q1. Simple Link와 Smart Link의 핵심 차이는?

Simple Link는 정적 연결 데이터이고, Smart Link는 런타임 상태 변경과 custom movement callback까지 가집니다.

Q2. Smart Link에서 custom move 진입 여부를 가르는 것은?

OnLinkMoveStarted()가 true를 반환하면 path following이 custom link 사용 상태로 대기합니다.
