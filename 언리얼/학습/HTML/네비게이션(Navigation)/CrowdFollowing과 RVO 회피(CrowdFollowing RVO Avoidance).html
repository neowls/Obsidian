Crowd / Avoidance

CrowdFollowing과 RVO 회피

CrowdFollowing은 PathFollowing의 Detour Crowd 확장이고, RVO Avoidance는 CharacterMovement가 현재 속도를 국소적으로 보정하는 기능입니다. 둘 다 회피지만 계산 주체와 계층이 다릅니다.

원본: CrowdFollowing RVO Avoidance.md 핵심: Path-aware Crowd vs Velocity-aware RVO

RVO는 authority-only 제약이 분명합니다

클라이언트에서는 등록 시 비활성화될 수 있고, 계산 함수도 ROLE_Authority가 아니면 바로 반환합니다.

복습 질문

Q1. CrowdFollowing이 path-aware인 이유는?

PathCorridor, nav poly, smart link 전환을 알고 path following 자체를 확장하기 때문입니다.

Q2. RVO가 velocity-aware인 이유는?

NavMesh 경로를 다시 만들지 않고 현재 속도와 주변 객체를 기준으로 새 velocity를 계산하기 때문입니다.
